# AIWomenhackathon

Hackathon project.

## Team setup

Each teammate clones this repo and works from their own machine:

```bash
git clone https://github.com/LouHan202/AIWomenhackathon.git
cd AIWomenhackathon
```

Standard workflow:

1. Create a branch for your work: `git checkout -b your-name/feature`
2. Commit and push: `git push -u origin your-name/feature`
3. Open a pull request into `main` and get it reviewed before merging.
